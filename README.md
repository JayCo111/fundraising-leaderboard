# 🏆 Fundraising Leaderboard

A real-time fundraising tracker with leaderboards, team statistics, and individual dashboards. Built with React and powered by Google Sheets as a database.

![App Screenshot](https://via.placeholder.com/800x400?text=Fundraising+Leaderboard)

## ✨ Features

- 📊 **Real-time Data** - Automatically syncs with Google Sheets
- 🥇 **Triple Leaderboards** - Personal stats, team rankings, and overall standings
- 📈 **Progress Tracking** - Visual progress bars and goal tracking
- 🏅 **Medal System** - Awards for top 3 performers
- 🔐 **Row-Level Privacy** - Parents only see their own student's buyer details
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile
- 🎨 **Modern UI** - Beautiful gradients and smooth animations

- **Database:** Google Sheets API
- **Hosting:** Vercel
- **Version Control:** Git & GitHub
